# E712_GUI — управление Е7-12 по КОП

Однофайловый инструмент (Python + tkinter) для измерителя иммитанса Е7-12
через адаптер UsbGpib (xyphro), USBTMC / NI-VISA. Файл:
`E712_GUI_v1_5_0.py`.

## Модель прибора

Е7-12 — калькулятор с двумя вычислителями и без процессора, архитектурно
зеркальный HP 4271A (1974): аналоговый вычислитель (четырёхпарный мост,
опорные напряжения «а»/«б», логометр) и цифровой с жёсткой программой ПЗУ
(32 такта, двухтактное интегрирование = деление длительностями). Числа не
случайны: такт 16 = 15915 мкс = 10⁷/(2π) — деление на ω выполнено
длительностью; подстройка нуля 30 000 мкс = OFFSET1 HP 30 мс; пульт
смещения 2.390.175 = HP 16023A (три галетника, 0…39,9, BCD 8-4-2-1).

Следствия, определяющие поведение программы:

| Свойство прибора | Поведение программы |
|---|---|
| Регистры write-only, состояние нечитаемо | строка теневого состояния «отправлено: …»; кнопок чтения состояния нет |
| ОЗУ отдаёт прошлый отсчёт | свежесть = ЗАП + время цикла; чтение по handshake |
| Байт данных = запись регистра | белый список табл. 5; посторонний байт блокируется |
| Команды табл. 6 идут с линией УП (ATN) | ЗАП = `assert_trigger()`, СБУ = `clear()`; как данные — никогда |
| КОП событийный | `time.sleep` в обмене отсутствует; таймаут VISA — граница ошибки |

## Уязвимость архитектуры: смещение

Документирована HP (OM 4271A, п. 3-56…3-57): «USE EXTREME CAUTION WHEN
WORKING WITH CHARGED CAPACITORS…», «bias current … must not flow into the
instrument», «DC BIAS VTG SWITCH … MUST BE IN OFF POSITION». Источник
смещения включён в тракт постоянно, вид (U/I) выбирается вслепую. Меры:

* смещение 0 при подключении, отключении, в `finally` каждой развёртки;
* **bias guard** — предизмерение без смещения, допуск по закону Ома
  (измерение 1 МГц ≠ DC учтено коэффициентами);
* **scan guard** — авто-стоп C-V по перегибу D (предвестник лавины
  варикапа), L-I по спаду L (насыщение) и росту R (потери/нагрев).

Не покрывается: замыкание самой линии «U/I СМЕЩ.» на корпус — линия за
фильтром генератора, тракту 1 МГц не видна; защита — плавкая вставка Пр9.

## Установка и запуск

```
pip install pyvisa pyvisa-py pyusb pyserial
pip install matplotlib pandas        # опционально, графики
# NI-VISA (Windows): https://www.ni.com/visa/
python E712_GUI_v1_5_0.py
```

Адаптер: UsbGpib V2 (VID 03EB, PID 2065), прошивка xyphro V2.4+.
При подключении программа сама шлёт `!autoid off` (иначе адаптер отправляет
`*IDN?` как данные и молча портит регистры прибора) и устанавливает
безопасное состояние: DCL + смещение U 0.0.

## Вкладки

| Вкладка | Назначение |
|---|---|
| Однократное | режим CG/CD/LR/LD, предел, уровень, смещение, усреднение |
| C-V | развёртка ёмкости по напряжению смещения, график |
| L-I | развёртка индуктивности по току смещения, график |
| Трёхполюсник | измерение трёхзажимных объектов |
| Подготовка | прогрев, балансы CG/LR, калибровка порога |
| Сортировка | Pass/Fail по карточкам порогов |
| Журнал | лог; «Режим отладки» дублирует сюда побайтовый обмен TX/RX |

Форматы отображения: SCI, ENG, СИ и **Табло** — в точности как на передней
панели (табл. 1 ТО): знак явный, решётка 5 цифр с запятой по пределу,
приставка и единица одной буквой либо пусто (D безразмерен).

## Сырой CSV сессии

Меню **Файл → Сырой экспорт CSV (авто)** — включён по умолчанию. Файл
`e712_session_ГГГГММДД_ЧЧММСС.csv` создаётся в папке скрипта при первом
измерении, пишется с flush, закрывается при выходе. **Файл → Сырой экспорт
CSV…** — копия всего буфера сессии в выбранное место (работает и при
выключенном авто).

Одна строка = одно реальное измерение прибора, из любой вкладки и любого
режима, всё выражение целиком:

| Столбец | Содержимое |
|---|---|
| `timestamp`, `t_s` | ISO-время и секунды от старта сессии |
| `context` | источник: single / three / C-V / L-I / sort / warmup; предизмерения bias guard помечены `…/preflight` |
| `mode`, `range`, `level` | условия (теневое состояние) |
| `bias_type`, `bias_set` | вид и уставка смещения в момент измерения |
| `raw_PC`, `raw_AC` | сырые 11-байтные сообщения КОП как есть |
| `primary_name`, `primary_SI`, `secondary_name`, `secondary_SI` | разобранные величины в базовых СИ (Ф, См, Гн, Ом) |
| `C_F`, `G_S`, `D`, `L_H`, `R_Ohm`, `Q`, `Z_Ohm` | вычисленные составляющие; пустая клетка = неприменимо |

Кодировка utf-8-sig (открывается Excel без вопросов), разделитель `;`
(настраивается), десятичная точка `.`, числа в `repr` — без потери точности.
Файл пригоден как вход для pandas / gnuplot / Excel-фильтрации.

## INI (`e712_config.ini`)

```ini
[DEFAULT]
gpib_addr = 1

[CODES]                 ; переопределение кодов табл. 5 (по умолчанию верные)
allow_experimental = 0  ; 1 = разрешить байты вне белого списка (осознанно!)

[BIAS_GUARD]
enable = 1
i_limit_ma = 39.9       ; база = аппаратный предел канала тока
margin = 0.5            ; разрешённая доля предела
l_factor = 5.0          ; запас R_DC < R(1 МГц) для LR/LD
u_compliance = 39.9     ; потолок источника тока, В

[SCAN_GUARD]
enable = 1
d_ratio = 3.0           ; C-V: стоп при D > D_min * ratio
l_sat_drop = 0.30       ; L-I: стоп при спаде L на долю от L0 (0.10 — ранний)
r_ratio = 2.0           ; L-I: стоп при росте R в разы от R0

[CSV]
delimiter = ;
```

## Шпаргалка протокола (табл. 5, стр. 46–47 ТО)

| Группа | Байты | Назначение |
|---|---|---|
| 0x0_ | 00 LD, 01 CD, 02 LR, 03 CG | эквивалентная схема |
| 0x1_ | 10 ×0,1, 14 ×1 | уровень сигнала |
| 0x2_ | 20 АВТ, 2E…2A пределы 1…5 | пределы |
| 0x3_ | 38 вывод РС, 30 вывод АС | селектор ОЗУ |
| 0x4_ | 40 Уст. I, 48 Уст. U | вид смещения |
| 0x5_/0x6_/0x7_ | +d: десятые / единицы / десятки (0…3) | разряды смещения |
| табл. 6 | ЗАП=GET, СБУ=DCL, ЭПО/ЗПО=SPE/SPD | только с ATN, через VISA |

Вывод прибора: ASCII `[+/-]N.NNNN E [+/-]NN[единица]`, 11 байт, конец = КП (EOI).

## Ограничения

* Прибор отдаёт содержимое ОЗУ, включая прошлый отсчёт (проверено на
  железе); программ синхронизируется запуском и handshake-чтением.
* Байт последовательного опроса существует (Мс7.1/Мс8.1/Мс7.4), семантика
  не документирована — снимается экспериментом `read_stb` до/после ЗАП.
* Геометрия окна рассчитана на 1023×600; живой прогон tkinter обязателен
  после правок раскладки.
